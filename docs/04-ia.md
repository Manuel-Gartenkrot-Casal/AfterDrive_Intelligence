# 04 · IA: dónde se usa y cómo

## Dónde se usa

| Paso | Tipo | Si el proveedor falla |
|---|---|---|
| Decidir si una noticia es del rubro | LLM (temperatura 0,1) | **Aprueba** (modo degradado). Si responde algo que no es JSON, rechaza |
| Vectorizar noticias, notas y consultas | Embeddings | Se guarda sin `embedding`; se completa después con `python -m afterdrive.ingesta.embeddings` |
| Redactar la nota | LLM (streaming) | Se informa el error y no se guarda nada |
| Evaluar la nota (checklist de 9 puntos) | LLM (temperatura 0,1) | La nota se guarda igual, con `evaluacion: null` y sin reescribir |
| Región de un texto, descubrir fuentes | **No es IA**: palabras clave | — |

## Un solo módulo habla con los proveedores

`afterdrive/ia/llm.py` es **el único lugar** que llama a un proveedor. Todos usan la API estilo OpenAI (`/chat/completions`, `/embeddings`).

```python
from afterdrive.ia import llm

texto = llm.completar(system="...", user="...", temperature=0.3)
vectores = llm.embeber(["texto 1", "texto 2"])
```

Cada proveedor es un **Perfil** (URL, modelo, modelo de respaldo, ajustes de redacción). Para cambiar algo de un proveedor se toca su perfil, no se agregan `if` en otros archivos.

## Proveedores

| `AI_PROVIDER` | Dónde corre | Modelo principal | Notas |
|---|---|---|---|
| `openrouter` (**producción**) | Cloud | `mistralai/mistral-small-3.1-24b-instruct:free` | **No tiene embeddings** |
| `nvidia` | Cloud | `moonshotai/kimi-k3` (respaldo `openai/gpt-oss-20b`) | Modelos que "razonan": 16000 tokens y una instrucción extra para que no escriban su razonamiento |
| `local` | LM Studio en tu máquina (puerto 1234) | `mistral-7b-instruct-v0.3` | Prompt compacto: los modelos chicos pierden instrucciones largas |

- **Los embeddings van por otro proveedor**: `EMBEDDINGS_PROVIDER=nvidia` (modelo `nvidia/nemotron-3-embed-1b`), porque OpenRouter no tiene.
- El proveedor se cambia desde el dashboard (vista Desarrollador, pie de la barra lateral) y queda guardado en Mongo.
- No se puede elegir `local` si LM Studio no responde.
- `llm.disponible()` cachea si el proveedor responde: 10 minutos si respondió, 1 minuto si no.

## Errores comunes

| Error | Qué hace `llm.py` | Qué hacés vos |
|---|---|---|
| 429 (límite de uso) | Prueba el modelo de respaldo y reintenta con espera creciente | Esperar o cambiar de modelo |
| 404/410 (modelo dado de baja) | Prueba el respaldo; si falla, muestra los modelos disponibles hoy | Cambiar `OPENROUTER_MODEL` / `NVIDIA_MODEL` |
| Sin respuesta en 180 s | Corta (`STREAM_READ_TIMEOUT`) | Reintentar |
| El modelo gastó los tokens razonando | Reintenta con el respaldo | — |

> Los modelos gratuitos cambian seguido. Si la generación empieza a fallar con 404/410, casi siempre es eso.

## Prompts

| Qué | Dónde |
|---|---|
| Clasificador de noticias y checklist de calidad | `ia/lm_studio.py` (el nombre es histórico; sirve para todos los proveedores) |
| Redacción de notas | `ia/redaccion.py`: piezas comunes + bloque de la persona + voz de la región |
| Parámetros del pedido (región, categorías, clientes) | `generacion/generar_nota_fase2.py` |

**Regla de oro de los prompts de redacción: no inventar cifras, empresas ni casos.** Los hechos salen solo de las noticias de contexto.

## Personas

| Persona | Enfoque |
|---|---|
| `comercial` (por defecto) | Vende una solución concreta al problema del lector |
| `analitico` | Explica un fenómeno técnico o de negocio a partir de las noticias |
| `periodistico` | Cuenta una novedad con pirámide invertida |
| `divulgativo` | Explica didácticamente un solo concepto |
| `ejecutivo` | Visión de alto nivel para quienes deciden |

## Evaluación que reescribe

Después de escribir la nota, el LLM la evalúa con el checklist de `ia/lm_studio.py`. Si falla un lineamiento **crítico** (`sin_alucinaciones`, `sin_paywall`, `no_repetitivo`, `estructura_correcta`), la nota se escribe una vez más con un pedido extra que dice qué falló, y queda la que cumple más lineamientos. Los críticos están en `CRITICOS` de `generar_nota_fase2.py`. El resultado se guarda en `calidad` y se ve arriba del checklist en el dashboard.

## Saneo

`ia/saneo.py` convierte la respuesta cruda en una Nota publicable o la rechaza con un motivo: quita envoltorios JSON y fences de markdown, corta texto degenerado, elimina oraciones y secciones repetidas, y **descarta la respuesta si el modelo escribió su plan o razonamiento** en lugar de la nota. Tiene sus propios tests (`tests/test_saneo.py`): si cambiás algo, agregá el caso que lo motivó.

## Jev (TypeSafe)

`ingesta/jev_clasificador.py` permite usar Jev como primer clasificador. **Hoy no se usa**: sin `TYPESAFE_API_KEY` se saltea y clasifica el LLM.
