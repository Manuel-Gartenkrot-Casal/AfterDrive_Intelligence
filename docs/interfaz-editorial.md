# Interfaz editorial

La identidad de AfterDrive conserva el rosa y la base violeta. El rosa marca
acciones principales y selección; las acciones secundarias usan superficies
neutras. El turquesa indica procesamiento, sin inventar porcentajes de avance.
IBM Plex Sans y radios de 5–6 px en controles y 10 px en contenedores reemplazan
el tratamiento redondeado anterior. Los estados conservan texto e iconos.

La sección visible **Actividad** mantiene el hash `#corridas` y las API
`/api/corridas` para conservar enlaces e integraciones existentes. La navegación
móvil se abre desde Menú. El dock acompaña las tareas entre secciones y respeta
la decisión de plegarlo. Las animaciones respetan `prefers-reduced-motion`.

En Crear nota se muestra el idioma que corresponde a las regiones elegidas,
según el comportamiento actual del sistema. No se modifica su configuración
ni la lógica de generación. La ayuda ofrece recorridos cortos para crear,
revisar y programar, además del recorrido completo.

La revisión muestra primero los avisos sobre datos y estilo; la calificación
manual queda desplegable. El backend, la generación y las integraciones
permanecen sin cambios.
